# 固定清单数据来源

清单生成日期：2026-09-19。`Resources/components.json` 是发布时固定文件，运行时不从网络更新清单。

- FFmpeg 9.0.1、llama.cpp `b10708`、ROCm `7.14.1` 的四个归档来自本机已下载文件；逐个读取实际字节数并计算 SHA-256。FFmpeg ZIP 展开文件合计 321,521,840 字节；llama ZIP 合计 1,116,913,437 字节；ROCm 两份归档合并后的本机目录为 14,743,492,512 字节。ROCm 两份归档都计入临时峰值。
- 必需模型按本机 Hugging Face 下载元数据固定提交。大文件 SHA-256 取下载元数据的 LFS 对象哈希，小文件按本机文件计算 SHA-256，下载字节数取实际文件大小。Qwen 模型有多个文件，因此每个文件作为独立、单源、单目标组件；界面将其合并展示为模型类别。可选 1.8B 的固定提交、大小和 LFS SHA-256 取 Hugging Face 官方 API；未下载该模型用于本次开发。
- `requirements.lock` 的 93 个固定包分别在 PyPI 或 AMD 官方索引选择与 CPython 3.12 Windows x64 匹配的文件，只读取包索引的文件大小，没有重新下载或安装依赖。合计基础依赖下载字节数为 1,719,591,979。AMD wheel 来源为 `https://stable.repo.amd.com/rocm/whl-next/`。
- 基础安装占用取当前 `.venv` 实际大小 5,122,488,720 字节、一次自包含 EXE 发布 139,973,726 字节和核心包展开 383,745 字节，合计 5,262,846,191 字节；清单向上留 37 MB 余量，设为 5,300,000,000 字节。基础临时峰值保守取两倍固定依赖下载量，即 3,439,183,958 字节。后续发布 EXE 如果显著增大，应重新核定该字段。

FFmpeg 的 gyan.dev `ffmpeg-release-essentials.zip` 名称不含版本；若上游更新导致固定 SHA-256 不匹配，安装器会停在当前组件并说明校验失败，不会接受新文件为本版本。正式发布前应重新核对并固定对应归档。现有 CLI 锁文件在全新独立 Python 环境复现尚未实测；清单数据核对不代替 G3 安装验证。
